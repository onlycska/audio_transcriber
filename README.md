## audio_transcriber

Минималистичный сервис для транскрибации длинных аудио‑записей на русском языке
с использованием Whisper (через `mlx-whisper`, GPU на Apple Silicon) и
diarization‑модели PyAnnote. Скрипт умеет:

- **распознавать речь целиком** с пословными таймстампами (без ручного
  чанкинга и артефактов на стыках);
- **определять спикеров** (speaker diarization) и привязывать реплики
  **пословно** — каждое слово относится к тому спикеру, чей интервал оно
  перекрывает;
- **склеивать соседние реплики одного спикера** с маленькой паузой между ними;
- **сохранять результат** в текстовый файл в папку `results`.

### Требования к окружению

- Python **3.13+**
- **Apple Silicon (M1/M2/M3/M4)** — `mlx-whisper` использует GPU через MLX
- Установленный `uv` (минималистичный пакетный менеджер и рантайм)
- Установленный `ffmpeg` (для авто-конвертации входных аудио в поддерживаемый формат)
- Аккаунт на Hugging Face и **персональный access token** для PyAnnote

### Инициализация проекта

1. **Установить `uv`** (если ещё не установлен).

   Инструкция и бинарники: [`https://docs.astral.sh/uv/getting-started/installation/`](https://docs.astral.sh/uv/getting-started/installation/).

2. **Установить `ffmpeg`**.

   Официальная формула Homebrew: [`https://formulae.brew.sh/formula/ffmpeg`](https://formulae.brew.sh/formula/ffmpeg)

   ```bash
   brew install ffmpeg
   ```

3. **Создать виртуальное окружение и установить зависимости**:

   ```bash
   uv sync
   ```

   Это создаст venv и установит зависимости из `pyproject.toml`.

4. **Получить `HF_TOKEN` на Hugging Face и принять условия моделей**.

   - Зарегистрируйтесь или войдите на Hugging Face.
   - Перейдите в настройки токенов: [`https://huggingface.co/settings/tokens`](https://huggingface.co/settings/tokens).
   - Создайте новый токен с нужными правами чтения (обычно `read` достаточно).

   > **Важная заметка про модели Hugging Face.**  
   > Для всех моделей, которые вы будете использовать (например, `pyannote/speaker-diarization-3.1`),
   > на странице модели на Hugging Face нужно принять условия использования и указать,
   > что вы используете её **в учебных/исследовательских целях**, если это требуется.  
   > Ссылки можно не искать заранее: если условия конкретной модели ещё не приняты,
   > при первом запуске скрипта появится понятная ошибка с прямой ссылкой на страницу модели,
   > где нужно нажать «Accept» и подтвердить режим использования.

5. **Создать `.env` (или экспортировать переменные окружения)**.

   Минимальный набор переменных:

   ```bash
   export HF_TOKEN="ваш_huggingface_token"
   export AUDIO_FILE="/полный/путь/к/аудиофайлу.wav"
   # необязательные, но можно переопределить:
   export NUM_SPEAKERS="2"
   # MLX-репозиторий модели Whisper (по умолчанию large-v3);
   # для большей скорости при близком качестве: mlx-community/whisper-large-v3-turbo
   export WHISPER_MODEL="mlx-community/whisper-large-v3-mlx"
   export RESULTS_DIR="results"
   export INITIAL_PROMPT="Разговор нескольких людей на русском языке."
   export LANGUAGE="ru"
   # макс. зазор (сек) при привязке слова к ближайшему интервалу спикера
   export FALLBACK_MAX_GAP="0.8"
   ```

   Вы можете использовать любой удобный способ загрузки переменных (`direnv`, `.env` + `dotenv`, shell‑скрипт и т.п.).

   Настройки логирования (опционально):

   ```bash
   # local/dev -> читаемые текстовые логи
   export APP_ENV="local"
   # явный override формата: 1 -> JSON, 0 -> text
   export LOG_JSON="0"
   # уровень логов
   export LOG_LEVEL="INFO"
   ```

6. **Запустить транскрибацию** (через `uv run`, чтобы использовать созданное окружение):

   ```bash
   uv run python -m src.presentation.cli.main
   ```

   После завершения работы в каталоге `results` появится файл вида
   `transcript_<имя_файла>_<timestamp>.txt` c пометками `[SPEAKER_XX]` перед каждой репликой.
